```powershell
        LogUpdated = (Get-Item -LiteralPath (Join-Path $_.FullName 'samples.jsonl')).LastWriteTime
    }
} | Format-Table -AutoSize
```

## 8. 必须在最终结论中保留的边界

- 真实直播的独立连接不是完全相同输入；有按类型计数、包字节与字段比例可核对。
- 并发各进程互相共享机器资源，窗口可能遮挡。已记录未隐藏／未最小化且页面为概览、浮窗 visible；**不保证每个窗口始终无遮挡或以同样频率完成实际绘制**。必要时后续做单实例复测，但别用本轮声明已完成所有稳定性验收。
- 新进程／当前较低流量与原数小时进程的高压力历史不同。
- 本轮没有账号同步监听器／BrowserHost，因此只能解释被测主程序路径。
- 不能以单个末值、前几分钟增长、GC 锯齿或“显示源都有 Dispose”独自判断永久泄漏。
