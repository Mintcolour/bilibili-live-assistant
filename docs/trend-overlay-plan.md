# 趋势分析与浮窗显示方案

实施基线：`aa1702a`（room-picker）。在 `trend-overlay` 分支分批提交。

## 历史分析

- 仅监视期间采集人数趋势及可核实的成员变化；断线、停止、请求失败保留空档，不以零填充，不将离榜推断为退舰或退团。
- 人数默认 60 秒、高能榜默认 60 秒前 50 人、大航海总榜默认 300 秒前 200 人；频率及范围有界可调。分页串行，复用已有请求。粉丝团记录人数及实际观察到的粉丝牌变化。
- 保存来源、采样时间、覆盖人数和接口总数；上舰事件与首次观察明确区分。
- 历史新增消息记录、趋势分析、成员变化三个页签，共用主播、日期、监视记录筛选，只加载当前页签。

## 浮窗

- 普通弹幕可选滚动、列表、固定网格；礼物/上舰与 SC 可选滚动、固定卡片；榜单可选滚动、固定面板。各区位置、字体等继续保留。
- 新默认：普通弹幕滚动，礼物/上舰及 SC 固定卡片，榜单固定面板，进房沿用最新三条定时隐藏。
- 礼物、上舰、SC 停留默认 20、30、60 秒，可调 5–300 秒；已显示卡片受保护，从完整显示开始计时。礼物区默认 3 张，SC 默认 2 张，可调 1–6；高度不足减少可见数量。
- 普通礼物待播最多 64 条/60 秒，拥堵保新；上舰和 SC 各最多 64 条/300 秒，保留入队顺序，上舰优先使用礼物区空位。所有省略计入未展示提示。
- 默认穿透，主窗口与托盘可临时交互；交互与位置锁定分离，可查看长 SC 和未展示记录。
- 固定内容不持续逐帧绘制，图片及队列有上限，隐藏、换房、退出时释放。

## 交付

仅静态检查、Release 编译、发布文件核对；不启动软件、不运行测试、不操作实际历史数据库。新目录发布，继承 room-picker 设置；编译不代表性能验证。
