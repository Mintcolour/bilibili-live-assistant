# 本地历史存档实施基线

以浏览器登录同步版为基线，在 `local-history` 分支分批实施：数据库与模型、采集与故障处理、历史页面、发布说明。

采用 Microsoft.Data.Sqlite 8.0.32；默认数据库位于 `%LOCALAPPDATA%/BilibiliLiveAssistant/history/history.db`，默认记录开启、长期保留、10 GiB 容量提醒。按可靠主播 UID、房间关联和主动监视段归档；UTC 时间与接收时本地日期分别保存，重连不拆段，异常结束在下次启动标记中断。

真实互动在显示缓冲之前投递，测试和示例不归档。礼物保存合并前数据；只按明确唯一事件 ID 去重。整数小单位记录免费/付费礼物及 SC，未知价格留空；不保存网络包或凭据。资料变化与每 60 秒已有统计/榜单结果保存快照，不增加请求。

WAL、单写入者、独立读取连接。每 500 条或有数据满 1 秒事务提交；队列同时限制 8192 条、约 16 MiB，预留 1024 条重要互动。故障优先继续监视，记录遗漏范围和类型，统计标记不完整。退出最多等待 5 秒。

独立历史页包含主播、日期、监视记录、统计和消息；每页 100 条、游标分页、虚拟化、单查询、取消和 5 秒超时。图片仅可见行加载，复用缓存，不自动展开媒体；新提交只提示刷新。类型、UID/昵称、正文筛选不改变统计底账。

设置沿用草稿保存应用；支持容量查看和提醒。清理展示范围及数量后确认，分批删除并更新统计；涉及当前段须先停止。释放空间和目录迁移须停止监视，迁移处理 WAL、临时复制、校验再切换，原库保留备份，失败继续原目录。

发布到独立目录并继承浏览器登录同步版设置。只静态检查、Release 编译、发布文件核对，不启动软件、不运行自动测试。运行、故障、图文和长期性能由用户手动验收；不能把编译通过视为性能验证。不会补录启用前或未监视时的数据，第一版不提供 CSV 导出。
