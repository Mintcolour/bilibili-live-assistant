# 高频气泡、表情与动画交付说明

发布目录：`artifacts/releases/hot-phrase-bubbles`。本机目录继承 `hot-phrases-live-stop` 当前设置，旧目录保留；缺少的新设置使用默认值。

## 使用方式

- 可视化设置 → **高频气泡**：调整显示开关、字号、表情大小、内容／背景不透明度、动画开关和时长。示例即时更新，点击「演示出入与换位」切换样本；保存并应用后改变实际画面，支持还原修改。
- 概览的提示位于弹幕列底部；紧凑桌面与 OBS 位于消息列表下方、进房／关注区上方。最多两行，优先显示排名靠前的项目；长内容省略，次数单独保留。无内容时收起。
- 普通浮窗改为独立的高频提示区域。进入现有浮窗调整模式后显示本地示例，可拖动、缩放；右键可调整字号、表情和透明度或隐藏。样式滑块即时预览，关闭小编辑器后保存。位置和尺寸单独保存，结束调整后恢复穿透。

## 本轮行为

- 最近 **30 秒**内普通弹幕整句重复至少 3 次，按次数降序显示前 5 项；空白归一化，保留大小写、标点和表情图片身份差异。次数会随窗口过期下降。
- 高频条目保留实际消息的表情元数据，使用现有图文分段器显示行内／整条表情。只有已经布局的原生气泡或可见网页图片会申请图片；无效图片保留文字标识。
- 半透明深色气泡、细边框和轻阴影；第一名使用暖色边框，次数独立显示。概览沿用现有表情动画偏好及共享的最多 4 个／10 FPS 动画调度；原生浮窗和 OBS 沿用既有静态首帧图片路径，本轮未新增 GIF 播放器。
- 默认 200 ms 下方滑入淡入、过期下移淡出、排名平滑换位。可关闭或设为 100–500 ms；单纯次数变化不重播入场，新位置变化接向最新布局，不排队。恢复页面／OBS 重连直接恢复当前内容。
- 聚合器仍限制到达时间队列 8192 项、不同内容 1024 项；样本不进入真实统计。每个显示区域最多 5 个活动气泡与 5 个短暂离场气泡。没有变化不重新测量／绘制；原生位移动画结束后停止新增帧需求，网页使用短时 WAAPI，无逐帧轮询。
- 隐藏、换房或回收时取消图片消费者并清理位图／租约与动画。表情尺寸变化会取消旧尺寸等待，迟到结果不能重新绑定。诊断补充独立高频浮窗位图和动画状态，紧凑位图账目包括气泡。
- OBS 延续受控本机图片地址、可见性加载和本机示例预览；不输出任意外链。样式选择器说明见 `obs-css-themes.md`。
- 原弹幕、显示队列、历史底账、礼物／SC 停留规则及上一版可靠下播自动停止逻辑保持。

## 验证边界

开发侧仅做静态检查、OBS JavaScript 语法检查、Release x64 编译与发布文件核对；不启动 App、BrowserHost、浏览器或 OBS，不运行自动测试。编译通过不代表显示和资源占用已通过实际验收。

## 用户手动验收

1. 30 秒内重复 3 次出现，最多 5 项；过期计数下降并消失。不同图片但相同占位名分别统计，测试弹幕不进入真实统计。
2. 行内表情、整条表情、透明图片、无效图片；概览开关表情动画。100%／150%／200% DPI 下核对清晰度与次数，窄区域／高字号不覆盖次数。
3. 连续新增、过期与名次变化的动画衔接；单纯次数更新不重新入场。关闭动画即时更新；100／200／500 ms 时长分别检查。
4. 概览底部、普通独立区域、紧凑和 OBS 底部的位置正确；无内容收起、最多两行且不轮播。普通独立区域可拉高查看更多，调整中使用示例，结束后恢复真实数据。
5. 设置预览／还原／保存，普通区域右键调整和重启后位置保留；OBS 刷新、断线重连不重播旧内容，样本不进入真实画面。
6. 动画中隐藏、切房和退出；反复开关概览／浮窗／OBS，观察图片租约、位图及动画需求回落。比较相同流量与布局下 CPU、内存长期走势，不以预算值代替实际占用。

分享包排除用户设置、历史库、诊断日志、OBS 密钥及用户导入素材；仅本机新目录继承设置。发布核对结果另见 `hot-phrase-bubbles-verification.md`。
