# 高能榜紧凑布局与关注重点提醒

## 本版变化

- 高能榜固定浮窗根据字号、头像与阴影计算紧凑行高，行间距由 8 px 改为 2 px；收紧头像及徽章之间的间隔。保留原字号、头像、粉丝牌、舰长身份与窗口位置，未重置自定义尺寸。
- 关注、特别关注和互粉使用独立标识、粉色强调线、浅色昵称与加粗金色提示文字。仅按接口已解析的互动类型识别，不根据消息正文或昵称推断关注。
- 关注浮窗默认停留 15 秒，可在“可视化设置 → 进房 / 关注”或浮窗“更多外观”中调整为 5–300 秒；普通进房继续沿用原有停留时间。
- 互动浮窗仍最多显示 3 条。关注优先排列，普通进房、点赞或分享不会提前顶掉关注；关注超过上限时替换较早关注，不排无界队列。
- 概览互动中的关注增加高亮和“已感谢”按钮，点击后显示确认状态。状态只属于本次运行中的这条概览记录；不写入历史库、不代表向观众自动发送消息。互动记录仍最多保留最近 15 条。
- 浮窗本地示例、设置预览及“显示示例消息”包含关注，方便调整与手动检查。测试示例不归档。

## 资源与交付

沿用事件驱动的固定内容绘制、现有图片缓存和到期唤醒；没有新增持续动画、网络请求或无限历史。保留字体、布局、场次历史、媒体与账号设置。

- 发布目录：`artifacts/releases/compact-ranking-follow`。
- 继承设置：`broadcast-history-modes`。
- 分享包：`artifacts/releases/compact-ranking-follow-win-x64.zip`，排除私有配置与历史库。
- 仅进行静态检查、Release x64 编译和发布文件核对；不启动软件或 BrowserHost，不运行自动测试，不读取用户历史库。编译不等于界面和性能验收。

## 手动验收

1. 高能榜切到固定面板，对比行高、间距；调整字号、缩放、阴影或带头像框成员，确认文字和徽章没有被裁切。
2. 打开浮窗调整或发送示例消息，查看新关注样式；普通进房与关注能够区分，修改关注停留秒数后保存生效。
3. 关注显示期间连续进房，关注不被顶掉；同时最多 3 条，关注到期后隐藏，关注高峰保留较新的提示。
4. 概览点击关注的“已感谢”，确认状态立即变化；换房、清空及 15 条上限继续正常工作。
5. 隐藏浮窗、结束调整或退出后，确认图片和到期等待释放；实际直播下观察 CPU 和内存。
