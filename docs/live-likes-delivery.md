# 概览与浮窗点赞提醒

## 显示与设置

B站独立的LIKE_INFO_V3_CLICK点赞事件现在作为互动显示在概览“互动”列和“进房／互动”浮窗，使用暖色点赞标识、昵称与“为主播点赞了”文字。旧INTERACT_WORD／INTERACT_WORD_V2中的点赞类型6也使用同样的标识。用户缺少昵称时显示匿名用户，不推断身份；不根据普通弹幕正文判定点赞。

沿用概览最近最多15条、浮窗最多3条的现有设置及上限；点赞使用互动区普通停留时间，可以在可视化设置或交互浮窗中调整。关注仍使用独立停留时间，已有关注提示在到期前不会被进房或点赞挤掉。预览和“显示示例消息”加入点赞示例，不进入真实历史。

高频点赞沿用现有UI批处理周期，同一批只展示最新的一条点赞提示，不新增轮询、动画、长期队列或独立窗口。开启本地历史时，网络入口在显示限流前归档实际收到的原始事件，历史的“进房／互动”类型中可以回看，不修改数据库版本或底账。概览、浮窗不是全部点赞事件的明细视图。

头像由原有全局显示设置控制。有上游头像链接时复用图片缓存；点赞缺少头像时显示昵称占位，不为短时提示额外按UID请求个人资料。进房头像独立开关仍只控制进房。

LIKE_INFO_V3_UPDATE是房间汇总，不会被伪装为某个用户的点赞提醒。本版增加的是可识别的点赞提示，没有增加累计点赞统计。B站未推送的个人点赞无法补录，提示条数不等于房间总点赞数。

## 开发核对与发布

只做静态核对、Release x64编译和发布文件检查，不启动正式软件、BrowserHost或自动测试，也不再次连接直播间运行模拟。新功能的真实事件显示和性能尚需用户手动验证，不将编译成功视为性能改善。

发布到独立目录artifacts/releases/live-likes，继承interaction-trade-filters版设置并核对字节一致；分享ZIP排除设置、历史库、诊断及调试数据。保留上一版礼物／SC筛选排序、ReadyToRun、DPI、SQLite、BrowserHost和分析工具。上一轮观察到的内存160 MiB超标问题没有在本功能中宣称解决。

请检查有观众点赞时概览与互动浮窗是否显示、停留后是否隐藏；同时出现关注和点赞时关注是否保留；高频点赞时只按当前刷新周期更新；关闭互动浮窗后不展示而历史继续按原规则保存。可先在“显示示例消息”或交互浮窗中查看点赞样式。
