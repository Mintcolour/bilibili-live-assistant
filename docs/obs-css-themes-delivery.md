# OBS CSS 主题交付与人工验收

本轮增加 OBS 专用四套模板、可视化网页外观、分区显隐、CSS 编辑和本地素材。入口：可视化设置 → 紧凑面板 / OBS / 金额停留 → OBS 网页样式 · 模板与 CSS。

首次展开才创建网页编辑控件。默认使用现有紧凑模板，基础外观沿用共享设置；旧设置缺少 `obsTheme` 时使用默认值。原生浮窗、礼物合并、队列、金额停留、登录与历史数据库不变。消息结构新增内容包装层，旧类名保留；旧 CSS 中依赖精确父子结构的规则可能需要调整。

说明见包内「OBS样式定制说明.md」，三份可导入样式位于「OBS样式示例」。分享包不包含个人设置、历史数据库、日志、本机 OBS key 或用户导入素材。

修改即时影响单独打开的网页示例，保存后才应用到实际 OBS。高级编辑区导出／复制仅包含自定义 CSS；模板及滑块由软件保存。样式更新不重置固定提示计时。OBS 原有地址保持不变；未启用 OBS 也可打开独立的示例预览。

预览复用网页源的渲染脚本，不在主程序常驻 WebView。单预览连接、300 毫秒合并推送；示例数据不进入真实消息、历史或 OBS。离开紧凑设置、隐藏主窗口或退出关闭预览；重新打开会生成新地址。预览不会读取真实弹幕或下载 B站图片。

资源上限：CSS 256 KiB；素材每个输入 4 MiB、处理后 8 MiB，静态图片最大 2048 × 2048；素材目录最多 64 项、32 MiB。素材只经受控文件名提供，保留本机访问、请求数量及两路图片／素材并发限制。远程 CSS、图片、字体和任意脚本不开放。

CSS 正常声明按基础、共享默认、模板、网页外观、自定义顺序叠加。OBS 内的不分层普通 CSS 可覆盖软件的分层普通 CSS；`!important` 按 CSS 标准规则处理。不宣称 LAPLACE CSS 直接兼容。

## 开发侧验证范围

只做静态检查、JavaScript／PowerShell 语法、Release x64 编译与发布文件核对。没有启动 App、BrowserHost、浏览器或 OBS，也没有运行自动测试。实际外观、兼容性与资源占用未经运行验证，编译通过不代表满足 160 MB 目标。

## 人工验收

1. 未修改主题时打开旧配置，检查所有消息类型、字号、阴影、透明表情和头像；原生紧凑面板仍按原外观显示。
2. 四种模板切换；关闭基础外观沿用，调整字号、头像／表情、背景、圆角、边框、阴影与间距；预览即时变化，真实 OBS 只在保存后改变。切换设置分类再返回，草稿保留；还原修改及恢复默认按说明生效。
3. 给昵称、正文、粉丝牌、各类消息、身份和金额档位分别加 CSS；未知金额不当零元；固定区和列表可分别定制。导入损坏、超大或非 UTF-8 CSS 时原内容保留。
4. 导入 PNG／JPEG 与字体；复制素材代码并预览，检查透明图片、中文字体、重复素材去重、大小／数量超限提示及素材删除后的回退。导出 CSS 不自动带素材。
5. 检查长 SC、混合语言、超宽内容、表情和图片延迟完成后的换行；大字号、窄画布、100%／150%／200% DPI 下不重叠。外层运动与内层 CSS 装饰互不争用。
6. 批量消息、礼物合并、SC／礼物到期、榜单变化、固定区收起；新增消息仍正确滑入上移，CSS 不改变队列和停留。恢复与重连不补播旧入场。
7. OBS 已连接时反复改主题，不需刷新页面；两路 OBS 与独立预览分别工作。另贴 OBS 属性 CSS，确认实际覆盖效果及其与软件预览的差异。
8. OBS 关闭、未开启监视时预览仍仅显示示例。隐藏／恢复预览标签、关闭标签、离开设置、隐藏主窗口和退出，检查预览断开与资源释放；旧预览页按提示重新打开，不能收到真实消息。
9. 相同吞吐、画布、帧率下比较内置模板和自定义样式的主程序／OBS CPU、私有工作集、图片延迟与长时走势。不要把素材磁盘预算或像素估算当成实际原生内存；昂贵滤镜和无限动画可能提高占用。
