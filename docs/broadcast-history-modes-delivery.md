# 直播场次归档与浮窗模式切换

## 本版变化

- 历史页新增“直播场次”。以接口提供的主播 UID、真实房间号、开播时间识别同一场直播；同场停止再开启监视，消息与统计仍可在同一场次查看。“更多筛选 → 监视记录”可以进一步查看其中一次监视。
- 一次监视期间遇到重新开播，也能按新的开播时间分成不同场次。日期筛选继续限制接收日期，跨午夜可扩大日期范围查看；趋势仍保留监视间的空档。
- 旧记录没有可靠开播时间，保留在“未识别场次（含旧版记录）”，不会按同一天或标题相同猜测合并。只保存实际收到的数据，未监视时的数据无法补回。
- 浮窗调整框直接显示模式按钮。普通弹幕一键切换“滚动／列表／卡片”；礼物与 SC 切换“滚动／固定卡片”，榜单切换“滚动／固定面板”。进房保持固定停留。
- 示例随模式切换：滚动时按该区域速度移动，列表固定排列，网格按可用宽度分列并展示示例次数。示例完全使用本地内容，不请求网络，不写入概览或历史。
- 继续支持选框内大小、字号、不透明度与隐藏开关；“更多外观”调整背景、阴影、速度和显示时间。

## 数据与资源

数据库自动事务升级至 v3，新增场次及监视时间区间关联，不重写旧消息。升级后请使用本版或更新版本；旧版不支持读取 v3。分场次清理只删除选中范围，日汇总随消息扣减；跨场次且无法拆分的缺口保留。

滚动示例复用现有共享动画时钟与缓存位图，每区最多 8 张／16 MiB；静止模式无逐帧更新，隐藏、关闭内容或结束调整停止示例动画并释放位图。只有变化的内容区域参与重绘。

## 手动验收重点

1. 同一场直播分两次监视：选择该场次可同时看到两次记录，子筛选可分别查看；重新开播后出现新场次。
2. 短号／真实房间号、跨午夜、断线重连：同场归并，未采集空档不补零；旧记录显示未识别场次。
3. 分别查看消息、统计、趋势、成员变化，再选择单次监视，确认范围一致；清理某场不影响另一场的消息与日汇总。
4. 进入浮窗调整，直接点击滚动／列表／卡片，确认按钮高亮、示例样式及真实显示模式一起变化。
5. 调整滚动速度、字号与透明度，缩放窗口、隐藏／恢复内容、结束交互，确认显示正常且没有持续后台示例动画。
