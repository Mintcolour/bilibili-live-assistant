# 紧凑面板人数、榜单与礼物布局修复

发布目录：`artifacts/releases/compact-status-gift-fix`。

## 本次变化

- 原生紧凑面板、OBS 网页源和设置示例统一采用左右分区：左侧房间人数／看过人数上下两行，右侧榜单前三名上下三行。
- 榜单只保留奖杯图标，移除“高能榜”文字和成员头像；保留名次、粉丝牌、舰长身份和昵称。接口不足三人时按实际返回显示，不填充假成员。
- 房间人数继续使用高能榜接口的总人数，看过人数继续使用观看统计；没有改成人气，也没有修改普通模式的榜单播报人数设置。
- 原生礼物卡片按实际字体、头像、内边距及阴影测量高度，预留两行正文空间。昵称限制在当前标题行，避免长昵称换行挤掉礼物正文；列表中的礼物图标在空间不足时与正文一起换行。
- 礼物名称、数量、金额仍使用原消息内容；超出有限区域的极长内容仍会省略，桌面阅读模式可点开查看原文。区域不足以完整显示标题与正文时不再绘制残缺的固定卡片，可扩大面板查看。
- 测量结果按消息类别缓存，仅在设置变化时重新测量，不增加逐帧图片请求、持续轮询或新的动画。榜单不请求头像。
- 保留 OBS 样式编辑、CSS 接口和示例文档。主题和自定义 CSS 仍可覆盖默认网页布局。

## 验证范围

只进行静态检查、Release x64 编译、发布与包内文件核对；没有启动 App、BrowserHost、浏览器或 OBS，没有运行自动测试。编译成功不能证明实际显示、性能或长期内存达标。

人工验收建议：

1. 在桌面和 OBS 检查两行人数、三行榜单，无“高能榜”文字和榜单头像；尝试 240／480 px 宽度及较长昵称。
2. 检查普通礼物、合并礼物、上舰的名称、数量和金额；开启粉丝牌／头像框／阴影，调整字号、内边距及面板大小，确认正文不再只剩图标与省略号。
3. 检查固定区和混合列表、设置示例及网页示例；切换普通／紧凑模式，确认原队列、金额停留时间和列表动画未变。
4. 使用原有自定义 CSS 时检查是否覆盖了顶部布局；可临时清空 CSS 与默认样式对照。
