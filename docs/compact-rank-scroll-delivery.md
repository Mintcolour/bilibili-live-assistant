# 紧凑顶部横排与榜单滚动

发布目录：`artifacts/releases/compact-rank-scroll`，继承 `compact-status-gift-fix` 当前设置，旧目录保留。

## 显示变化

- 顶部恢复一行横排：观众人数、观看人数、奖杯图标、榜单。
- 两项人数固定；奖杯后的前三名组成一条横向列表，每秒 40 px 从右向左循环滚动，保留名次、粉丝牌、身份及昵称，不显示头像和“高能榜”标题。
- 房间人数继续取高能榜接口总人数，观看人数继续取观看统计；没有切换为人气。原生紧凑面板中较大的纯数字人数以万／亿缩写，窄面板的人数区可适当减小字号，为榜单保留空间。
- 适用于原生桌面、OBS 网页源、桌面编辑示例和两种设置预览；没有修改普通模式的榜单播报规则。
- 保留上一版礼物正文高度、昵称占位与图标换行修复，以及原有队列、金额停留时间和 CSS 功能。

## 资源与生命周期

原生顶部缓存人数与榜单两张静态位图；列表没有出入动画时，帧回调只清理并重绘顶部榜单区域，不重新排版或重建消息位图。复用已有动画时钟和帧率设置。关闭顶部、隐藏浮窗、换房或退出会释放对应位图并停止无用帧回调。

OBS 使用浏览器 Web Animations API 和一个有限的循环副本，不增加逐帧 JavaScript 轮询。人数内容单独更新；字体和可用宽度变化时重新测量，隐藏、断线和移除旧榜单时取消动画并解除尺寸观察。原生设置预览复用两张图片和 WinUI 变换动画，离页释放。

## 验证范围与人工检查

只做静态检查、Release x64 编译和发布文件核对，不启动 App、BrowserHost、浏览器或 OBS，不运行自动测试。实际显示、CPU 和内存尚未实测。

请手动检查：

1. 人数与图标是否保持一行，前三名是否完整循环可见；没有榜单或不足三人时是否正常。
2. 240／480 px 宽度、大字号、长昵称、粉丝牌及舰长身份下的裁剪、可读性和滚动。
3. 桌面／OBS／本地预览、人数更新、房间切换及 OBS 刷新后的滚动和资源释放。
4. 礼物、SC 正文和列表动画是否保持正常；隐藏再恢复、阅读旧消息时榜单是否继续独立滚动。
