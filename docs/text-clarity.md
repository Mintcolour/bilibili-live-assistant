# 主窗口字体清晰度

2026-10-13 用户反馈主窗口全部字体发糊，而非仅滚动弹幕。静态检查发现源清单与 `gift-merge-overview` 发布 EXE 的嵌入清单均缺少 DPI 感知声明；没有发现主窗口对全部文字进行位图缩放的代码。上一版继承设置的概览字体为 Microsoft YaHei UI、字号 18、昵称字号 15，文字不透明度为 100%。

`artifacts/releases/dpi-aware/` 在应用清单中声明 PerMonitorV2，同时保留旧系统可识别的 `true/pm`。声明在创建窗口前生效，避免由 Windows 对不感知 DPI 的窗口进行整体位图放大，让 WinUI 使用当前屏幕缩放比例绘制文字。跨屏 DPI 改变由框架处理，不增加轮询、每帧文字重绘或额外位图缓存。

本次不改变用户字体、字号、透明度及弹幕合并规则，继承 `gift-merge-overview` 设置。只做 Release 编译、清单与发布文件检查，未启动软件或运行测试。清单缺失已确认，但尚未通过用户现场窗口的 DPI 状态确认它是否是唯一原因；Windows 程序兼容性缩放覆盖、显示分辨率与字体设置仍可能影响显示。悬浮窗的透明位图文字属于另一条绘制路径，不据此宣称其清晰度已经修复。
