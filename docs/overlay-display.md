# 分区显示与外观设置

2026-10-13 设置入口已重做为分类实时预览与草稿布局编辑，见 [可视化设置说明](visual-dashboard.md)。以下分区计时、滚动和资源规则继续沿用；旧版设置页的按钮名称以新版说明为准。

2026-10-12：按用户确认方案，普通弹幕、礼物/上舰、SC、榜单滚动，进房/关注固定停留。五类使用独立窗口和队列，各自可拖动、调整尺寸；新版发布目录 `artifacts/releases/classified-scroll/`。

## 使用方法

1. 在“显示设置 → 选择展示区域”中选择要调整的类别。
2. 各区独立设置字体、字号、颜色、透明度、粗体、斜体；四类滚动内容支持细描边。头像、粉丝牌、身份徽章和图片表情沿用现有图文样式。普通弹幕与 SC 可分别设置行内表情和整条图片表情高度。
3. 普通弹幕、礼物/上舰、SC、榜单分别设置滚动速度（30–500 px/s）。速度固定，内容越长，完整掠过所需时间越久。
   “动画流畅度”控制四个滚动区域的帧率：30 FPS 省电、60 FPS 平衡（默认）、120 FPS 或跟随屏幕刷新率（最高 240 FPS）。跟随模式以普通弹幕窗口所在屏幕为准；其他选项也不超过该屏幕的刷新率。高刷模式会增加活动时的绘制开销，消息接收间隔与动画帧率独立。
4. 礼物设置合并窗口（0–30 秒，默认 3 秒）；进房设置每条停留时间（1–120 秒，默认 5 秒）及同时显示上限（1–3，默认 3）。榜单设置播报间隔（5–600 秒，默认 30 秒）、人数（1–10，默认 3）及是否在开头显示人气/看过统计。
5. 点击“保存并应用显示设置”。切换区域保留尚未保存的编辑；复制外观只复制字体、颜色、表情尺寸等，不覆盖各区速度、计时和布局。
6. 开启“编辑区域位置”，拖动窗口或边缘调整尺寸，松开鼠标后保存。也可填写精确坐标和尺寸；留空坐标与 0 尺寸使用默认布局。关闭编辑后鼠标穿透。
7. “显示示例消息”包含同人同礼物的合并示例、带表情的长 SC、四条进房提示和前十名榜单数据，供手动验证。

## 分类与计时

| 类别 | 展示规则 | 默认节奏 |
|---|---|---|
| 普通弹幕 | 独立滚动轨道，拥堵省略过时消息 | 120 px/s，沿用已有速度 |
| 礼物/上舰 | 从第一笔起收集同人同礼物，窗口结束后一次播报，后续赠送不延长窗口 | 收集 3 秒，120 px/s |
| SC | 按收到顺序滚动；长内容按完整字形/表情边界分段，标注段号，同条各段不插播其他 SC | 120 px/s |
| 人气/高能榜 | 播报最新快照，人数统计置于开头；上次未滚完则跳过当次，无旧榜单队列 | 每 30 秒，前 3 名，120 px/s |
| 进房/关注 | 固定位置显示最新三条，新人替换最早一条，每条从出现起独立计时隐藏 | 每条 5 秒 |

特别长的榜单也会分段接续，仍算同次播报，不预生成多张宽位图。礼物合并只接受相同账号、相同礼物和币种；匿名身份只允许相同非空事务 ID，不能凭昵称合并。

`gift-merge-overview` 版起，概览礼物列表也使用同一合并窗口，即时在原行累加数量／金额。0 秒关闭两处合并，窗口从第一笔起固定计时，后续消息不会延长；已播出的悬浮消息不回改，既有历史不追溯合并。

滚动轨道高度随字体和表情大小调整；实际同时数量受区域高度限制。进房默认区域增高以容纳三条，已有自定义布局继续保留，较矮时需自行调高。旧默认单条/3 秒设置迁移为三条/5 秒。普通弹幕的旧全局速度作为新独立速度的初值。

## 资源与拥堵规则

- 普通弹幕最多 64 个活动位图，接收和待播缓冲各 64 条；排队超过 2 秒加批处理延迟后省略。
- 礼物最多等待 64 条合并组，拥堵时先播最新就绪组；超过 15 秒或合并窗口加 10 秒（取较大值）后省略过时提示。
- SC 最多等待 64 条、最长 5 分钟；队列满时省略新到 SC，已接受的消息保持收到顺序。全部 SC 过载时不能保证每条都滚动，概览仍按自身记录上限保留全文。
- 待播项只保存消息数据。长 SC 开始播放时才拆段，当前段开始时才生成位图；同一时刻只有一段 SC 和一段榜单占用活动位图。
- 进房悬浮最多三条，移除或到期立即取消图片等待、释放位图；概览互动历史仍保留最近最多 15 条。
- 榜单接口已有请求仍取前十名，概览继续默认展示前三名；播报间隔只决定展示，不增加 HTTP 请求频率。人气和看过人数分别保留最新值，避免单项更新覆盖另一项。
- 活动消息移动时复用位图和原生 Alpha 画布，按小数坐标移动，仅重绘受影响轨道。四区共用动画时钟，无活动滚动时停止帧唤醒；进房到期、待播就绪/过期及榜单播报采用到时唤醒，没有空闲逐帧轮询。
- 图片加载沿用共享有界缓存和两路下载并发；可见消息等待缓存队列空位，单张图片就绪就刷新，慢头像不会挡住已下载的表情。隐藏、关闭、切房时取消控件等待并释放活动图像，共享缓存继续按容量限制管理。
- 拖动布局不重置进房寿命；字体等外观变更后 SC 从当前整条重新分段播放，避免新字号溢出或丢失后续内容。
- 五个区域独立保存布局，文件写入仍串行；隐藏/销毁窗口释放原生画布，切房清空旧消息和榜单快照。

此前发布的文字填色、细描边、Alpha 透明、悬浮首次呈现、图文头像、表情主动加载和缓存容量修复继续保留。图片源缓存上限和动画默认静态策略不变。

本版仅静态检查、Release 编译和发布；未启动软件，也未运行单元、界面、直播间或性能测试，实际显示和资源占用由用户手动验证。

流畅度优化版发布到 `artifacts/releases/overlay-smooth/`，继承分类滚动版设置。移除 33 ms 动画定时器及普通弹幕达到 12 条自动降到 50 ms 的行为；活动帧使用共享后台等待、DWM 合成节奏和独立可等待计时器，UI 最多一个待处理帧。每帧直接提交各区画面，避免动画更新后再排一次呈现消息；独立轨道的重绘区域保持分离，减少对空白区域的清除和绘制。不改变图片缓存、礼物合并、SC 顺序和榜单播报规则。

2026-10-13 图文榜单版发布到 `artifacts/releases/rich-rank/`，继承流畅度优化版设置。悬浮榜单播报中，看过人数使用眼睛图标，人气使用火焰图标，高能榜使用奖杯图标；成员使用与弹幕相同的圆形头像、粉丝牌、大航海身份徽章和昵称样式，并显示名次。头像、粉丝牌、身份的显示仍受现有外观开关控制。

榜单沿用原有接口请求。接口缺少头像或身份字段时，仅按正值 UID 复用现有有限消息历史中最近三分钟的信息；明确为空的粉丝牌或 0 级身份不会被旧信息覆盖。没有新增个人资料请求或持久用户缓存；未知身份不生成徽章。真实接口字段和显示效果尚未通过直播间验证。

榜单按完整成员分段，每段位图宽度最多 4096 像素；待播段只保留数据，仅当前段生成活动位图，图片就绪后刷新。继续复用共享图片缓存及两路下载并发，移动帧不重新生成成员图文。播报间隔、人数、独立速度和隐藏释放规则保持原有设置。“显示示例消息”中的前三名分别带舰长、提督、总督身份，供手动检查。本版只完成静态检查、Release 编译与发布，未启动软件或运行测试。
