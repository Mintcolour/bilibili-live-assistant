# 趋势分析与浮窗模式交付

分支：`trend-overlay`。发布目录：`artifacts/releases/trend-overlay`，继承 `room-picker/settings.json`；不会在实施过程中启动程序、连接直播或操作用户实际数据库。

## 本轮变更

- SQLite v2 事务迁移，保存分级人数／榜单采样、失败覆盖和成员观察变化；删除、清理和迁移兼容新表。
- 历史三个页签，最多 1200 次趋势摘要、100 条成员变化分页，点击后才加载榜单成员；图文只在可见行加载。
- 普通弹幕独立选择滚动／列表／网格，礼物和 SC 选择滚动／定时卡片，榜单选择滚动／固定面板。
- 默认礼物 20 秒、上舰 30 秒、SC 60 秒，当前卡片受保护，有界队列、上舰优先、未展示记录、概览／托盘临时交互。
- 可视化设置保留草稿、保存应用与还原，新增模式、背景、尺寸和独立停留时间。

## 静态交付检查

Release x64 编译，发布 ReadyToRun 与桥接程序，核对 SQLite 8.0.32／AMD64／PerMonitorV2、配置继承哈希和 ZIP 条目哈希。证据保存为 `artifacts/trend-overlay-verification/release-verification.json`。不运行软件或自动测试；编译成功不代表接口、显示或性能已经实机验证。

## 用户手动验收

1. 连接真实房间后离开概览，观察历史人数／高能榜／大航海继续按设置采集；停止后停止。断线、重连、跨午夜及跨监视段曲线有正确空档。
2. 切换主播、日期、监视记录与页签，取消查询、翻页、选择快照；确认范围／总人数、部分失败及未知身份均准确，不把离榜当退出。旧版快照标记新鲜度未知。
3. 真实上舰事件区别于首次观察，粉丝牌变化不冒充完整粉丝团名单。删除主播、日期清理和目录迁移包含新数据；维护前停止监视。
4. 礼物／上舰共享 3 张和 SC 2 张默认卡片；定时结束前不被挤走，停留分别为 20／30／60 秒。满队列、超时、合并与上舰优先符合说明，未展示数量可展开。
5. 分别切换各区域模式；普通网格不挪槽、精确合并、表情差异、悬停保护和隐藏功能正确。交互开关能恢复穿透，位置保持锁定，完整 SC 可展开。
6. 窄区域、大字号、缩放、隐藏、换房与退出后资源释放；图片、媒体不串位。设置预览与保存后的实际外观一致。
7. 大量真实消息和长时间记录时手动观察 CPU、内存、写入增长。固定卡片空闲时无持续动画，但实际性能仍需实机验证。

详细限制与操作见同目录“本地历史使用说明.md”。
