# 媒体预览与固定弹幕卡片

本轮发布到独立目录 `artifacts/releases/media-cards/`，继承 `dpi-aware` 版的 `settings.json`。旧设置缺少的新字段使用下列默认值，原字体、布局、Cookie、DPI 声明和礼物合并规则继续保留。本轮未改登录步骤，也未创建登录分支。

## 使用入口与默认值

“可视化设置”新增“媒体预览”和“概览卡片”。左侧本地静态示例、右侧对应开关与滑块；切换类别保留草稿，点击“保存并应用”后改变实际窗口，“还原修改”恢复已保存值。媒体示例可切换 B站／Steam，滑块及示例切换不访问网络。页面隐藏后停止预览绘制并释放视图。

| 设置 | 默认值 | 可调范围 |
| --- | --- | --- |
| 概览媒体 | 开启、自动内嵌 | 关闭／自动内嵌／点击展开 |
| 悬浮媒体 | 开启，同时最多 2 条 | 关闭或 1–4 条 |
| 资料卡宽度／封面高度 | 420／96 px | 260–800／48–160 px |
| 普通弹幕模式 | 列表 | 列表／卡片 |
| 期望列数／卡片高度 | 2／180 px | 1–4／140–320 px |
| 自动防刷屏隐藏 | 关闭 | 开启／关闭 |
| 防刷屏阈值／隐藏时间 | 20 次／30 秒 | 2–1000 次／5–600 秒 |

## 媒体预览

普通弹幕和 SC 识别 BV 号、含 BV 的 B站视频链接，以及 `app/730`、`steam:730`、`steam 730`、Steam 商店链接。相同消息中重复媒体去重，最多保留 3 项。B站展示静态封面、标题、播放量、作者头像与昵称；Steam 展示静态封面、名称、开发商和中国区简体中文资料中的价格，接口缺失价格时显示“价格暂无数据”。作者头像遵循共享头像开关。

概览自动模式对可见消息请求资料；点击模式展开后才请求。每项可折叠，并提供“打开原页面”按钮，只在用户点击后调用默认浏览器。不播放视频、不加载网页，也不自动打开外部链接。

悬浮媒体附在原消息下方，沿用普通弹幕或 SC 的滚动速度；每条仅第一项，长 SC 仅第一段附图。普通弹幕提前占用连续轨道，同时检查纵向空间与前一条的横向间距。没有轨道、高度不足或已达到共享媒体上限时只显示原文，不为媒体排队补播或替换已经滚动的消息。悬浮区域缩小时，无法容纳的媒体释放并退回原文。完整滚出后释放消费者和组合位图。

封面、两行标题及作者／摘要行在加载前预留空间，加载中、失败状态维持尺寸。资料或图片到达只重绘对应悬浮消息的缓存位图，逐帧移动不重新请求、解码或排版。不可访问视频、不存在游戏、请求繁忙、超时和失败显示编号及简短状态，不阻塞弹幕原文。

## 固定网格

概览普通弹幕列头点击“卡片”，或按 `Alt+C` 切换；输入框、密码框及数值输入获得焦点时不触发快捷键。SC、礼物、互动列与桌面悬浮保持原有展示方式。

新内容先填第一个空槽；同样内容原位更新次数及最后收到时间。满格时替换最久没有更新且未被悬停保护的内容；全部槽位受保护时，只进入原有历史。手动隐藏留下空位，不移动其他卡片。卡片不定时消失，也不增加持续动画。列表／卡片切换和页面隐藏取消相应视图的等待并释放图片。

列数按每列至少 200 px 适配，行数按可用高度计算，总槽位最多 32；调整布局按槽位编号保留能容纳的内容，超出的槽位释放。重复匹配只修剪首尾空白、折叠连续空白，保留大小写、标点、字符和表情 URL 的差异。

点击“×次数”查看发言者、次数和最后发言时间。正值 UID 归并身份，每张卡最多保留 64 人；超过上限显示“未展开次数”。匿名 UID 只计“身份未知”，不根据打码昵称推断身份。

隐藏按钮仅隐藏该内容在概览卡片中的显示，不影响原历史、悬浮、SC 或礼物。手动清单最多 512 项，满时提示清理，卡片列头提供清除入口。自动隐藏达到阈值后暂时抑制同内容，期间不累计触发次数，到期后的新消息重新计数；暂时隐藏清单也限制为 512 项。清空概览记录、换房或重启清除隐藏状态。

## 资源边界与接口

- 接收消息只检测引用，不等待网络。固定接口为 B站 `x/web-interface/view` 和 Steam `api/appdetails`，媒体资料请求不携带登录 Cookie，不跟随重定向。
- 资料最多 2 个并发、16 个待处理引用；相同媒体共享请求。队列满时返回繁忙状态，不新增后台等待队列。缓存最多 128 项，成功 10 分钟、失败 5 分钟；请求超时 10 秒，正文最多 1 MiB。
- 图片复用已有两路下载、24 MiB 内存和 128 MiB 磁盘缓存；保留单图大小与解码尺寸限制。只允许 B站及指定 Steam CDN 域名，Steam 图片使用对应 Referer，不开放任意链接下载。
- 回收、折叠、页面隐藏、换房及退出取消消费者等待；没有消费者的未完成资料／图片请求取消。共享缓存按既有预算淘汰，不代表隐藏后进程内存会立刻降为零。
- 卡片按消息批次通知，仅变化的槽位更新视图，不轮询卡片状态。

## 手动验收

本次仅静态检查、Release 编译及发布文件核对，未启动软件、未运行自动测试，也未调用真实 B站／Steam 资料接口。编译通过不代表接口或性能已现场验证。

可在概览菜单“显示示例消息”或设置页“保存并显示示例”生成多身份重复内容、BV／Steam 引用和带媒体的长 SC。这是用户主动触发的演示，媒体资料可能访问真实接口；设置面板中的静态预览仍完全使用本地示例。

1. 用 BV 号、完整链接、三种 Steam 简写及商店链接验证识别、重复引用去重、每条最多三项；分别验证自动／点击模式和手动打开原页面。
2. 验证无效或不可访问编号、请求失败、超时和缺价格。加载前后卡片尺寸应稳定，正文继续显示。
3. 混合普通弹幕与媒体，调窄区域、调大字号；观察两条媒体并行滚动、超限退回原文、缩小区域释放附图、长 SC 后续分段不重复附图。
4. 验证固定槽位、大小写／标点／表情图片差异、重复计数、多 UID 与匿名详情、悬停保护、满格替换、隐藏留空和临时隐藏到期后的重新计数。
5. 验证切换模式、隐藏／最小化窗口、换页、换房、清空记录及退出后的资源释放；大量消息下观察 CPU、内存及显示稳定性。
