# 历史主播选择与历史页整理

基线：`local-history` 分支的 `ad7be86`。

- 概览增加带头像、名称与房间号的历史主播选择框，选择后填入房间号，点击开启监视；监视中锁定切换。
- 主播头像使用现有有界图片缓存，下拉按需查询，只有可见项加载头像。
- 历史页采用主播侧栏、当前主播标题、日期筛选和数字摘要；高级筛选收起，消息列表占主要空间。
- 加入删除主播全部存档的操作，与日期范围清理分开；展示数量后确认，正在记录的存档不允许删除。
- 按主播选择、历史布局与维护、发布说明分批提交。
- 只静态检查、Release 编译和文件核对；不启动软件、不运行自动测试。新目录发布，继承 local-history 版设置。
