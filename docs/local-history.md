# 本地历史使用说明

本版新增 SQLite 本地存档与独立“历史记录”页。默认开启，只从本版启用并开始监视后保存实际收到的数据；不会补回先前丢弃的内存消息或未监视期间的数据。

## 查阅

1. 左侧导航选择“历史记录”，选择主播或待识别房间。列表显示最近 2000 个主播，可按昵称、曾用名、UID 或房间号查询更早的主播。
2. 选择开始/结束日期和监视记录，点击“查询”。日期按收到消息时的本地日期分类，原始时间以 UTC 存储。跨午夜仍是同一监视段；记录选择默认显示所选日期范围最近 500 段，查看更早记录可缩小日期范围或保持“全部监视记录”。
3. 可筛选消息类型、发送者 UID、昵称与正文关键词。UID 0 表示身份未知，不按遮挡昵称推断为同一人。类型、发送者与正文筛选仅改变消息列表，不改变所选主播、日期与监视段的统计底账。
4. 每页 100 条，按接收时间倒序，可查看更早消息和返回上一页。分页游标保留最近 256 页的返回路径；“有新记录 · 刷新”回到最新。条件变化会取消旧查询；单次查询最多 5 秒，超时可缩小日期范围。
5. 双击消息查看原始接收/上游时间、结构化礼物字段和可靠事件 ID。“资料与榜单快照”查看所选范围最后保存的资料、统计和榜单；“归档缺口”查看最近 100 项遗漏范围、类型与数量。

头像、粉丝牌、徽章与表情沿用概览外观。图片链接复用已有缓存，仅可见行持有图片；历史不永久归档图片，图片不可用时显示昵称、文字或表情标识。历史不自动展开媒体预览。

## 统计与监视段

- 从主动开启到主动停止监视是一段，换房建立新段；自动重连和账号更新不拆段。主播取得正值 UID 后按 UID 归档并关联房间号，改名不会另建主播。
- 礼物按显示合并前的数据保存；只按接口明确提供的唯一 ID 去重，目前 SC 的可靠 ID 已接入。礼物交易/连击标识不会作为唯一事件 ID。
- 付费礼物显示已知金额，免费礼物单独显示数量，SC 单独显示金额；金额用整数千分之一元保存。缺失价格或缺乏可靠金额语义时留空，上舰通知的原始价格字段不会被猜测换算为实际收入。
- 资料变化单独保存；每 60 秒保存已采集的人气、看过人数及榜单，不增加网络请求。没有采集到的数值不会填成真实的零。
- 存储故障或拥堵时监视继续。概览与历史显示归档异常；有缺口或中断的监视段标为“不完整”，不会假装补回遗漏。极端拥堵产生的未归属缺口单独说明，不计为某个主播的确定遗漏。
- 下次启动会将上次未正常结束的监视段标为“中断”。退出的存档提交最多等待 5 秒；未确认全部保存时给出提示。若目录本身不可写，缺口辅助文件也可能无法落盘，中断段会明确提示末尾遗漏数量可能无法确定。
- 同一存档目录只允许一个本版实例写入。双开时第二个实例会显示归档异常并继续监视，避免误标第一个实例的监视段。

## 存档设置与维护

“可视化设置 → 本地历史存档”提供记录开关、目录、占用和容量提醒。默认目录：

```text
%LOCALAPPDATA%\BilibiliLiveAssistant\history\history.db
```

存档独立于发布目录，升级软件继续使用同一库。默认长期保留，不自动删除；默认达到 10 GiB 提醒，可调整。占用包含数据库、WAL 和共享内存文件。新设置先更新静态预览，点击“保存并应用”后生效；“还原修改”恢复已保存设置。

更换目录前先停止监视，可输入目录或点击“选择存档目录”。保存后暂停查询、提交待写数据、处理 WAL、复制至目标临时文件并校验，再切换配置。目标已有 `history.db` 时拒绝覆盖；失败继续原目录。成功后原数据库保留为备份，由你手动清理。不要在数据库正在记录时单独复制 `history.db`，WAL 可能包含尚未合入的记录。

“历史记录 → 存档维护”中：

- **清理所选主播与日期范围**：先展示主播、日期、监视段与记录数量，确认后后台按批删除。同步更新汇总并清理范围内资料、快照与缺口；列表类型、UID、昵称与关键词筛选不缩小清理范围。涉及正在记录的段时须先停止监视。已删除空间可供后续写入复用。
- **释放磁盘空间**：停止监视后整理数据库，将空闲页归还磁盘；可能耗时并需要额外临时磁盘空间。

本版不提供 CSV 导出。Cookie、登录令牌和完整网络包不会进入历史数据库。真实历史仍包含发送者和消息内容；发布 ZIP 不包含用户配置、数据库或缺口辅助文件。

## 手动验收

本次仅进行静态检查、Release 编译和发布文件核对，没有启动软件或运行自动测试。请手动确认：

| 场景 | 应看到的结果 |
| --- | --- |
| 重启、升级、主播改名、短房间号、身份迟到 | 历史保留，按可靠 UID 合并分类；资料未取得时显示待识别房间 |
| 停止再开启、账号更新、自动重连、换房、跨午夜 | 主动开启建立新段，重连不拆段，换房不串档，午夜按接收日分类 |
| 礼物合并、重复 SC、免费礼物、未知价格、匿名 UID | 原始礼物未被展示合并改变，可靠 ID 去重；免费/付费/SC 分开，未知值不猜测 |
| 日期/类型/UID/昵称/正文筛选、翻页、快速切换条件 | 一页最多 100 条，旧查询取消，底账不随列表筛选改变 |
| 图文回看、滚动、隐藏页面、切换页 | 样式与表情保留；仅可见行加载，离开页面释放图片引用，媒体不自动展开 |
| 测试弹幕、显示示例、已有压力示例 | 不进入真实历史；检查归档吞吐应使用实际直播消息 |
| 磁盘故障、真实突发消息、修复后继续 | 监视不中断，遗漏/中断明确可见，修复后继续保存，不宣称补回缺失数据 |
| 清理与取消、释放空间、迁移及迁移失败 | 确认范围准确、汇总同步；原库保留，目标已有库不覆盖，失败不切换配置 |
| 长期运行与大量存档 | 手动观察 CPU、内存、数据库增长及查询耗时；编译通过不视为性能验证 |
