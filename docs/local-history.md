# 本地历史使用说明

SQLite 本地存档默认开启，只从启用并开始监视后保存实际收到的数据；不会补回先前丢弃的内存消息或未监视期间的数据。本版增加人数趋势、榜单快照与成员观察变化。

## 查阅

概览顶部的标题、主播选择和监视操作合在一行。主播选择框可以直接输入房间号、B站直播链接或名称，停顿 300 毫秒后自动匹配本地历史；候选显示头像、名称和房间号。输入有效房间号但没有对应历史时，提供“连接新房间”候选，也可直接点击“开启监视”。点击下拉箭头可查看最近主播；每次最多显示 50 位，输入名称或房间号可缩小范围。选中主播后同一输入框显示名称，点击“开启监视”即可连接；正在监视时先停止才能切换。输入搜索不请求直播资料，新房间资料沿用开启监视后的获取流程。无头像时显示昵称占位；关闭候选列表释放头像引用。窄窗口收起次要统计，保留主播输入与监视操作。

1. 左侧导航选择“历史记录”，左侧头像列表选择主播或待识别房间。列表显示最近 2000 个主播，可按昵称、曾用名、UID 或房间号搜索并按 Enter 或点击放大镜，查询更早的主播。
2. 右侧突出当前主播、直播场次、日期与弹幕／礼物上舰／SC／互动数字摘要。选择场次会自动查询；日期和消息类型修改后点击“查询记录”。同场直播的多次监视可统一查看，也可在“更多筛选”中选择其中一次监视。日期按收到消息时的本地日期分类，原始时间以 UTC 存储。跨午夜仍是同一监视段／直播场次，扩大日期范围可以查看完整已采集内容。
3. 展开“更多筛选”选择监视记录、发送者 UID、昵称与正文关键词，点击上方“查询记录”。监视记录默认显示所选日期范围最近 500 段，查看更早记录可缩小日期范围或保持“全部监视记录”。UID 0 表示身份未知，不按遮挡昵称推断为同一人。类型、发送者与正文筛选仅改变消息列表，不改变所选主播、日期与监视段的统计底账。“重置筛选”保留日期，清除详细条件。
4. 每页 100 条，按接收时间倒序，可查看更早消息和返回上一页。分页游标保留最近 256 页的返回路径；“有新记录 · 刷新”回到最新。条件变化会取消旧查询；单次查询最多 5 秒，超时可缩小日期范围。
5. 双击消息查看原始接收/上游时间、结构化礼物字段和可靠事件 ID。主播标题右侧的信息图标查看所选范围最后保存的资料、统计和榜单；警示图标查看最近 100 项归档缺口。鼠标停留在金额摘要上可查看未知价格数量等补充信息。

头像、粉丝牌、徽章与表情沿用概览外观。图片链接复用已有缓存，仅可见行持有图片；历史不永久归档图片，图片不可用时显示昵称、文字或表情标识。历史不自动展开媒体预览。

## 统计与监视段

- 从主动开启到主动停止监视是一段，换房建立新段；自动重连和账号更新不拆段。主播取得正值 UID 后按 UID 归档并关联房间号，改名不会另建主播。
- 直播场次位于监视记录之上，复用房间接口返回的真实房间号和开播时间，与主播 UID 共同识别。同场多次监视统一汇总；一次监视跨重新开播时按时间区间关联不同场次。场次列表显示日期范围内最近 500 场，更早场次可缩小日期范围。旧版或缺少可靠开播资料的记录放在“未识别场次”，不按日期或昵称猜测合并。全部页签沿用场次范围，不补录监视间隙。
- 礼物按显示合并前的数据保存；只按接口明确提供的唯一 ID 去重，目前 SC 的可靠 ID 已接入。礼物交易/连击标识不会作为唯一事件 ID。
- 付费礼物显示已知金额，免费礼物单独显示数量，SC 单独显示金额；金额用整数千分之一元保存。缺失价格或缺乏可靠金额语义时留空，上舰通知的原始价格字段不会被猜测换算为实际收入。
- 资料变化单独保存；人数趋势默认每 60 秒、高能榜前 50 名每 60 秒、大航海总榜前 200 名每 300 秒采集。人数复用房间资料结果，榜单按需串行分页，与概览复用短期结果；没有采集到的数值不会填成真实的零。
- 存储故障或拥堵时监视继续。概览与历史显示归档异常；有缺口或中断的监视段标为“不完整”，不会假装补回遗漏。极端拥堵产生的未归属缺口单独说明，不计为某个主播的确定遗漏。
- 下次启动会将上次未正常结束的监视段标为“中断”。退出的存档提交最多等待 5 秒；未确认全部保存时给出提示。若目录本身不可写，缺口辅助文件也可能无法落盘，中断段会明确提示末尾遗漏数量可能无法确定。
- 同一存档目录只允许一个本版实例写入。双开时第二个实例会显示归档异常并继续监视，避免误标第一个实例的监视段。

## 存档设置与维护

### 趋势分析与成员变化

历史右侧的“消息记录／趋势分析／成员变化”共用主播、日期和监视记录。类型和正文仅用于消息页，成员页支持 UID 与昵称。只有当前页签加载并显示数据，不持续轮询；提交新记录后点击刷新。

- **趋势分析**：分别查看大航海、高能、粉丝团人数，以及当前采样范围首末增减。每次最多读取范围内最近 1200 次采样；查看更早时段请缩小日期范围。点击曲线或选择采样时间，读取该次人数或榜单明细，展示“已采集／接口总人数／采集上限”。快照列表也包含大航海总榜。
- **成员变化**：每页 100 条，可查看姓名、UID、粉丝牌、身份、名次、贡献、陪伴天数的前后值。首次观察与实际上舰事件分别标注，不从离榜推断退舰或退团。接口未提供的身份和数值保持未知。
- **粉丝团覆盖**：本轮保存接口提供的总人数与实际消息中的粉丝牌观察；旧外观数据不包含粉丝牌主播 UID，因此粉丝牌观察明确标为“归属未核实”，不当成本房完整成员名单。
- 仅监视且直播连接可用时采集；断线写入空档标记、停止后停止请求。自动重连不拆监视段，恢复后重新取样。接口失败保留状态和部分覆盖，不重复将旧值作为新采样。
- 旧版监视段没有新采样时，可展示原快照中可解析的人数；标为“旧版缓存采样，新鲜度未知”，不重建旧成员变化。

采样频率和人数上限位于“可视化设置 → 本地历史存档”。人数 30–3600 秒、高能榜 30–3600 秒／1–200 人、大航海 60–7200 秒／1–300 人。修改仍需保存并应用。榜单分页一次总预算 30 秒，单页 15 秒；正文最多 1 MiB。部分失败可以重试，不影响弹幕监视。

数据库事务升级为 v3，包含直播场次及监视时间区间关联；新表跟随删除主播和目录迁移。旧软件不支持读取 v3 数据库，请继续使用本版或更新版本。

### 浮窗模式与礼物提醒

“可视化设置”中分别选择普通弹幕、礼物／上舰、SC、人数／高能榜，调整模式、尺寸、外观并实时预览；保存后应用。已有字体、位置、媒体及账号设置继续保留。首次升级默认普通弹幕滚动、礼物及 SC 定时卡片、榜单固定面板，后续保存的模式不再被默认值覆盖。

- 普通弹幕可选滚动、最近 100 条固定列表、固定网格。网格最多 32 槽，精确合并、64 个身份详情及防刷屏规则沿用概览卡片设置；各自保留隐藏状态。悬停保护槽位，点击查看发言者，右键卡片隐藏，右键空白处清空隐藏清单。清空概览记录或换房会清空本次浮窗状态。
- 礼物默认 20 秒、上舰 30 秒、SC 60 秒，均可设 5–300 秒。礼物／上舰共享区域默认 3 张，SC 默认 2 张，数量可设 1–6。时间从首次完整显示起计算；新消息不抢占已显示的卡片。礼物图标使用消息自带的 CDN 图片，未提供时显示本地图标，不额外请求礼物目录。
- 普通礼物先按既有窗口合并，待播最多 64 条／60 秒；拥堵时保留较新提示。上舰和 SC 各 64 条／5 分钟，保留队列顺序；上舰优先使用礼物区下一个空位。所有超限或超时条目计入“未展示”；调整浮窗时，打开该区域顶部的类型菜单可查看最近 100 项省略原因。该数量仅属于本次浮窗，完整记录仍可在概览和存档中查看。
- 可见卡片受区域高度、字号和 16 MiB 位图预算限制。空间不足会减少实际数量，不会缩小字号挤入卡片；进入调整后可直接增高区域。榜单固定面板可滚轮查看其余名次。显式保存过的小区域继续保留。
- 高能榜固定面板使用紧凑行高与 2 px 行间距，头像、粉丝牌、舰长身份继续显示，不重置字号与自定义窗口尺寸。
- 关注／特别关注／互粉提示采用独立标识与强调色，默认停留 15 秒，设置或浮窗“更多外观”可调整为 5–300 秒。进房沿用原时间；仍最多显示 3 条，关注优先，普通互动不顶掉尚未到期的关注，关注满额时保留较新的提示。概览中可将关注标为“已感谢”，仅保留本次运行中的记录状态，不向观众发消息；互动历史仍最多最近 15 条。
- 概览工具栏或托盘选择“调整浮窗位置、大小与类型”，各区出现编辑边框；拖动顶部空白处移动，拖动边缘或角点缩放，选框内模式按钮直接切换滚动、列表、卡片或面板（按区域支持的类型）。位置和尺寸在拖动结束时保存，类型选择后保存。点击“完成”恢复穿透，平时不显示编辑边框和操作提示条。结束调整后恢复真实内容。隐藏浮窗会结束交互并释放图片、取消等待及清空待播。
- 固定内容没有帧循环，只在收到消息、图片到达、到期、调整布局或交互时更新。媒体沿用全局并发数量限制；固定卡片只有尺寸足够时附第一项媒体，否则保留原文，完整 SC 通过点击查看。

概览头像中的本次监视曲线、概览人数摘要和浮窗人数均取高能榜接口的总人数，使用人数图标；不使用人气值，也不把当前已加载的榜单成员条数当总人数。看过人数仍独立显示。曲线最多保留 240 次实际采样，断线留空，人数未知显示“—”，不增加网络请求。

历史页首次进入即显示已监视主播，不受右侧日期和消息筛选影响。按最近监视排序，每批 200 位，较多时点“更多主播”继续查看，无需先搜索；仅可见行加载头像。搜索用于筛选，清空搜索自动恢复主播列表。

#### 浮窗内调整外观和时间

进入“调整浮窗”后，各区改为本地示例，不必等待真实消息。选框直接提供模式按钮，普通弹幕一键选择“滚动／列表／卡片”，礼物和 SC 选择“滚动／固定卡片”，榜单选择“滚动／固定面板”；选中项高亮，选择后自动保存。滚动示例按区域速度移动，列表、网格卡片和固定面板保持静止，进房保持固定停留。示例不进入概览或历史，不发起图片与媒体请求。调整期间真实采集和存档继续，退出后浮窗恢复接收新消息，人数／榜单恢复最新数据，不补播调整期间的消息。滚动示例复用共享动画时钟和位图缓存，隐藏或结束调整即停止。

选框直接提供“大小、字号、不透明度”滑杆和加减按钮，拖动即时预览，松开后自动保存。“隐藏／显示”控制整个类别的悬浮内容；隐藏后调整框仍保留，便于重新开启，退出调整后隐藏的区域不再显示。普通弹幕也可单独关闭，不影响概览和存档。低透明度只影响示例，工具条保持清晰。窄框中的控件自动换行，过矮区域临时增高以容纳控件与示例；只有手动拖动／缩放时才保存位置与尺寸。

进入浮窗调整后，点击各区顶部“更多外观 → 大小、透明度、背景与时间”。可调整每条内容缩放、字号、整体不透明度、卡片高度，以及背景和文字阴影。背景不透明度 0 表示完全透明；榜单默认透明，卡片不再重复铺矩形底。文字阴影在消息位图生成时缓存，可关闭或调整强度、范围、偏移和颜色。可视化设置中提供相同选项。

调整先预览，保存后保留，取消或关闭恢复原设置。礼物、上舰、SC 的卡片停留时间分别设置，计时从首次显示起算；进房设置自己的停留时间。滚动模式通过速度控制完整滚出所需时间，榜单另设播报间隔。新内容间隔 0–30 秒可限制起播或补入卡片的速度，SC 同一条的后续段连续；固定列表、网格和面板使用此值控制批次显示更新，不增加接口请求，也不改变存档采集频率。

高能人数统一使用真实房间号查询的榜单首页总人数。面板最新首页结果会复用到概览统计、曲线与浮窗，旧采样不会覆盖新采样；查询时间不同可能仍有短暂刷新差异。之前存档不会反推或改写。

“可视化设置 → 本地历史存档”提供记录开关、目录、占用和容量提醒。默认目录：

```text
%LOCALAPPDATA%\BilibiliLiveAssistant\history\history.db
```

存档独立于发布目录，升级软件继续使用同一库。默认长期保留，不自动删除；默认达到 10 GiB 提醒，可调整。占用包含数据库、WAL 和共享内存文件。新设置先更新静态预览，点击“保存并应用”后生效；“还原修改”恢复已保存设置。

更换目录前先停止监视，可输入目录或点击“选择存档目录”。保存后暂停查询、提交待写数据、处理 WAL、复制至目标临时文件并校验，再切换配置。目标已有 `history.db` 时拒绝覆盖；失败继续原目录。成功后原数据库保留为备份，由你手动清理。不要在数据库正在记录时单独复制 `history.db`，WAL 可能包含尚未合入的记录。

“历史记录 → 右上角主播操作”中：

- **删除此主播全部存档**：不受日期或筛选条件限制，确认框显示主播与全部条目数。确认后删除其互动、资料、快照、缺口、统计和监视记录，并从历史主播列表移除；正 UID 主播跨房间归档一起删除，未识别房间只清理所选房间。不可撤销，涉及正在记录的监视段时先停止。概览下次展开选择框时更新列表；之后再次监视仍会重新建立存档。
- **清理所选主播与日期范围**：先展示主播、日期、场次、监视段与记录数量，确认后后台按批删除。同步更新汇总并清理范围内资料、快照与缺口；按场次清理时保留无法拆分的跨场次缺口；列表类型、UID、昵称与关键词筛选不缩小清理范围。涉及正在记录的段时须先停止监视。已删除空间可供后续写入复用。
- **释放磁盘空间**：停止监视后整理数据库，将空闲页归还磁盘；可能耗时并需要额外临时磁盘空间。

本版不提供 CSV 导出。Cookie、登录令牌和完整网络包不会进入历史数据库。真实历史仍包含发送者和消息内容；发布 ZIP 不包含用户配置、数据库或缺口辅助文件。

## 手动验收

本次仅进行静态检查、Release 编译和发布文件核对，没有启动软件或运行自动测试。请手动确认：

| 场景 | 应看到的结果 |
| --- | --- |
| 重启、升级、主播改名、短房间号、身份迟到 | 历史保留，按可靠 UID 合并分类；资料未取得时显示待识别房间 |
| 停止再开启、账号更新、自动重连、换房、跨午夜 | 主动开启建立新段，重连不拆段，换房不串档，午夜按接收日分类 |
| 礼物合并、重复 SC、免费礼物、未知价格、匿名 UID | 原始礼物未被展示合并改变，可靠 ID 去重；免费/付费/SC 分开，未知值不猜测 |
