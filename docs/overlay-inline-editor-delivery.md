# 交互浮窗示例与选框直接设置

分支 `overlay-inline-editor`，实施基线 `3cd7188`，基线提交 `5224ab3`。发布到独立目录 `artifacts/releases/overlay-inline-editor-v2`，继承 `overlay-appearance-v2/settings.json`。不启动程序、不运行自动测试、不访问实际历史数据库。

## 本次行为

- 进入交互调整，普通弹幕、礼物／上舰、SC、进房、人数／榜单统一使用静态示例，始终停留以便调整。采用真实消息渲染器和当前字体、徽章、缩放、背景及阴影设置，头像使用本地轮廓示例，不下载外部图片。
- 示例只在浮窗绘图层生成，不送入事件、概览或历史。调整期间浮窗停止接收实时显示消息、停止动画、释放已有消息图片和媒体等待；概览与历史的实际采集照常。结束调整后展示新收到的消息，人数与榜单恢复最新资料，不排队补播调整期间内容。
- 选框中直接放置大小（50–200%）、字号（12–72 px）、不透明度（10–100%）滑杆和加减按钮。拖动预览合并为 60 ms 一次的单次唤醒，松开自动保存；没有持续绘制、逐帧计时或空闲轮询。
- 工具条独立于内容透明度，调低不透明度仍可操作。控件和命中区域使用同一几何计算；窄框自动换行，矮区域临时扩展以显示工具与示例。
- 选框直接显示“隐藏／显示”按钮；隐藏后保留框和控制，退出调整后才完全隐藏该类别，重新进入可恢复。兼容旧显示开关，普通弹幕也可独立关闭；不隐藏概览或删除历史。
- 各区设置在保存锁内读取最新配置并合并，防止快速调整多个区域时相互覆盖。调整隐藏开关、滑杆不写入临时扩展的窗口尺寸。
- 原“外观 / 类型”及背景、阴影、停留时间、显示间隔等详细设置继续可用。详细面板维持保存应用和取消草稿的规则。
- 示例图片缓存每区最多 8 项、16 MiB，重绘只发生于设置、大小或显示状态变化；隐藏、结束调整、销毁时释放缓存。

## 验证范围

只执行静态差异检查、Release x64 编译、发布文件核对。核对结果位于 `artifacts/overlay-inline-editor-v2-verification/release-verification.json`，覆盖 ReadyToRun、BrowserHost、SQLite 8.0.32、AMD64、PerMonitorV2、继承配置字节一致性及 ZIP 文件哈希。编译不代表实际显示效果或性能已经验证。

## 用户手动验证

1. 无监视／没有消息时进入调整，五个区域都有相应示例；有真实消息进入时示例不滚走，概览和历史继续收到真实内容。
2. 直接拖动三种滑杆及点击加减按钮，大小、字号、不透明度与示例一致；10% 不透明度下工具条清晰可操作，松开后重新进入或重启保留设置。
3. 隐藏所有类别（包括普通弹幕），调整框保留；结束后内容隐藏，再进入可恢复。设置页显示开关一致，不影响概览和存档。
4. 快速交替调整多区、拖动滑杆到框外松开、切换模式、打开详细面板、保存或取消，设置不互相覆盖；窄框与矮框仍可找到控制，拖动和四边缩放可用。
5. 结束调整后示例全部消失；真实新消息恢复，人数与榜单使用最新数据。反复显示／隐藏、换房、退出后观察资源释放，以及静置时 CPU、内存是否稳定。
