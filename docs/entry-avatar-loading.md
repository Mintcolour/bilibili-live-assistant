# 进房头像独立加载开关

“可视化设置 → 进房 / 关注”及“概览消息”增加“加载进房头像与头像框”，互动浮窗的“更多外观”也可直接切换。默认开启，旧设置文件没有该字段时保持原显示。

关闭后概览、历史进房行及浮窗不创建进房头像控件、不补全头像、不枚举头像及头像框下载地址，并回收头像占用的布局宽度。全局头像开关仍优先生效。关注、互粉、分享、点赞等明确的非进房互动沿用原设置；历史中已收到的头像链接不变。取消及租约释放沿用各页面和浮窗现有的样式切换路径，不取消其他消费者共用的图片。

已完成静态调用核对及 Release x64 编译；未运行正式应用、BrowserHost 或功能自动测试。需要在隔离验收中确认关闭后进房头像请求为零、其他类型不受影响。此开关本身不能证明默认设置下达到 160 MiB 上限。
