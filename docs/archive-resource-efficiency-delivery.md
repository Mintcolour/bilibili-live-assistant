# 运行资源调查与历史存储精简

发布目录：`artifacts/releases/archive-resource-efficiency`。继承 `hot-phrase-bubbles` 当前设置，原运行目录与用户数据库保持不变。

## 实际调查结果

2026-10-17 对已运行约三小时的进程做只读检查，没有停止、重启或裁剪工作集：

- 19:47 私有工作集约 262 MiB、私有提交约 383 MiB；总工作集包含共享页，不能混作任务管理器私有工作集。
- 19:49 的 20 秒 .NET 计数显示托管堆约 28–29 MiB，GC 提交约 48–52 MiB。
- 用户随后开启采样；19:50 起的前 91 个点约 7.5 分钟，主窗口一直在性能页、紧凑浮窗可见。私有工作集峰值 285.02 MiB，私有提交峰值 409.45 MiB，托管内存峰值 43.85 MiB，CPU P95 0.772%（按逻辑处理器数归一化）。这不代表概览同时可见的验收场景。
- 此区间 WinUI 图片源和租约已归零，静态像素缓存约 17 MiB，紧凑浮窗位图与画布合计约 2 MiB；不能用这些计数解释全部进程占用，也不能据此认定所有剩余部分都是 WinUI 泄漏。GC 提交量、托管对象量、原生像素估算之间存在包含关系，不能相加当作工作集。
- 文字绘制代码中，`StringFormat.GenericTypographic` 已返回拥有原生资源的新对象，旧路径又克隆并只释放副本，原对象依赖终结器回收。本轮移除克隆，让每次文字测量／绘制及时释放该对象。字体、字形路径、阴影、透明度与刷新率不变。此问题是已确认的分配与延迟释放来源，未证明它解释了全部内存。
- 19:47 存档目录约 497 MiB，其中数据库约 492 MiB；独立图片缓存约 9 MiB。数据库表没有图片 BLOB，只保存公开资料、图片链接、文字与索引。约 27.6 万条事件、11.8 万条成员变化及分析快照构成主要体积，不能通过“删除库内图片”解决。

## 本轮修改

1. 修复浮窗文字格式对象的延迟释放；采样增加区间文字测量／绘制次数。
2. 增加 SQLite 分配器的当前字节数和不重置的进程生命周期峰值。它们不等于存档文件大小，不涵盖进程所有原生内存。旧日志缺少新字段时，分析脚本返回 null。
3. 新记录使用稀疏 JSON：仅省略可选 null 字段，以及有模型默认值的空外观字符串、默认粉丝牌颜色、零等级、false 房管和空表情集合。姓名、正文、时间、金额、数量、身份、有效链接及表情图片身份保持；可靠的零金额／零数量与未知 null 仍有区别。
4. 必需的空列表（如采样 members）、其他类型的空字符串和 false 不因精简被删除；旧 JSON 继续可读。成员变化先把旧状态转换为当前序列化格式再比较，避免格式升级伪造变化。
5. 历史页原有「释放磁盘空间」在停止监视后，分批整理旧事件、成员变化、分析快照、榜单和资料的 JSON，再 VACUUM。每批最多 128 行，文本缓冲约 2 MiB 加一行，逐批事务并处理 WAL；取消保留已完成且可读的批次，可重新执行。保留全部事件、数组元素和非空未知字段；不重算底账、不删除图片链接。未对正在运行的原库执行此操作。

对近期事件和成员变化各 5000 行、分析快照约 2600 行只读抽样，空字段与默认值精简后的 JSON 文本分别减少约 65%、48%、38%。这不是整个数据库的缩小比例；索引和页利用率仍占空间。实际节省量应在用户整理后检查。

## 使用与手动验收

- 当前监视结束后关闭旧软件，使用新目录中的程序，避免两个实例同时写同一历史库。新版本继续读取本机原数据库。
- 新记录直接使用精简格式。要缩小既有数据库：停止监视 → 历史记录 → 菜单 → 释放磁盘空间。确认框会说明保留内容和临时磁盘需求；这不是删除历史。单纯升级不会在线改写全部旧记录。
- 核对旧记录和新增记录的头像／表情、免费礼物、未知价格、零金额、空榜单、成员详情及统计相同；升级后无凭空出现的成员变化。
- 整理后核对记录数、场次、筛选排序和统计，检查磁盘体积；取消后重新整理应可继续使用。
- 保持概览与浮窗同时可见，开启资源采样。比较相近流量、布局、DPI、远程桌面／本地环境下的私有工作集、GC、SQLite 原生量、文字测绘量和终结器观测。160 MiB 目标本轮尚未实测达到。

开发侧仅静态检查、Release x64 编译、只读运行诊断及发布文件核对；不启动 App、BrowserHost、OBS 或自动测试。没有强制 GC、工作集裁剪、用户历史删除或在线 VACUUM。编译成功不作为内存改善或数据库维护的运行验证。发布核对见 `archive-resource-efficiency-verification.md`。

分享包不含用户设置、历史库、诊断日志或 OBS 密钥。仅本机独立目录继承设置。
